SEMICONDUCTOR DATA · STUDY 03

가상계측과 이상탐지

센서 신호로 두께를 예측하고 생산 검사 결과를 분류합니다.

전체 흐름3D로 보는 VM가상계측분류와 지표검증과 한계용어 정리출처
01 / THE BIG PICTURE

하나의 센서 데이터, 서로 다른 질문

공정이 끝난 뒤 무엇을 알고 싶은지에 따라 정답의 형태와 모델을 다르게 선택합니다.

PVD와 SECOM은 서로 다른 공정의 데이터입니다.

PVD AlCu

AlCu 금속층을 물리기상증착(PVD)한 뒤 두께를 측정한 데이터입니다. X는 익명화된 센서 집계값이고 Y는 17개 지점의 두께입니다.

SECOM

반도체 생산의 센서 특성과 내부 검사 pass/fail 결과입니다. 1,567개 샘플 중 불합격은 104개이며, 두께 정답은 제공하지 않습니다.

02 / EXPLORE IN 3D

3D로 보는 공정과 가상계측

공정 중 센서는 설비 상태를 기록하고, 계측 장비는 공정 후 박막 두께를 측정합니다.

가상 모형은 챔버 속 웨이퍼와 박막, 주변 센서로 구성됩니다. 센서와 두께 측정을 활용하여 가상계측 모델을 학습합니다.

학습과 예측의 차이

학습할 때는 과거 관측의 센서 입력 X와 대응하는 실측 두께 Y를 함께 사용해 모델을 맞춥니다. 사용할 때는 새 공정의 센서값을 넣고 모델이 예상 두께를 출력합니다. 나중에 실측이 가능하면 예측값과 비교해 오차 및 공정 변화 여부를 확인합니다. 데이터의 X·Y 행 대응은 모델을 학습하기 전에 확인해야 합니다. 모델의 예측은 간접 추정이며 계측기의 측정값을 보장하거나 대체한다고 단정할 수 없습니다.

예측 시점과 데이터 누출: 공정 종료 직후에 예측하려면 그 시점까지 실제로 얻을 수 있는 센서값만 입력에 넣습니다. 종료 후 수집되는 정보, 두께 측정 결과나 그로부터 계산한 값을 입력에 섞으면 정답을 미리 본 것과 같아 평가 성능이 부풀려집니다. 학습·평가 분할 후 결측치 대체, 스케일링과 변수 선택도 학습 쪽에서만 맞춥니다. 공개 센서 집계값의 수집 시점은 별도 확인이 필요합니다.

SECOM은 별개의 흐름입니다. SECOM에서는 같은 모형의 두께를 예측하는 것이 아니라, 별도 데이터의 센서 특성으로 생산 검사 합격/불합격을 분류합니다. PVD와 SECOM의 샘플이나 정답은 서로 연결되어 있지 않습니다.

03 / VIRTUAL METROLOGY

측정 전, 두께를 예측한다

실제 계측기는 공정이 끝난 웨이퍼에서 두께를 측정합니다. 가상계측(Virtual Metrology, VM)은 이전에 쌓인 센서값과 실측값의 관계를 학습해, 새로운 공정의 두께를 추정합니다. 이는 모델의 예측값이므로 실측과 차이가 있을 수 있습니다.

평균 두께 예측

17개 측정값의 평균을 하나의 결과로 삼습니다. 공정 전체의 두께 수준을 이해하기 쉽습니다.

17개 지점 예측

위치별 값 각각을 예측합니다. 평균이 같더라도 지점별 두께 분포가 다른 경우를 살펴볼 수 있습니다.

모델을 비교하는 방법

다중회귀는 입력 변수가 예측값에 기여하는 관계를 선형식으로 표현합니다. 트리 기반 모델은 입력값을 기준으로 데이터를 나누어 복잡한 관계를 학습할 수 있습니다. 어떤 방법이 좋은지는 처음 보는 데이터의 오차로 비교합니다.

실제 PVD 파일의 주의점: 97개 센서 열의 물리적 의미는 익명화되어 있으며 X와 Y의 행 대응 기준, 두께 단위·변환 방식 및 실규격은 확인이 필요합니다. 예측 오차의 단위도 목표값과 같으므로, 원 단위를 모르면 nm로 해석할 수 없습니다. 목표 규격 대비 오차는 규격과 스케일이 확인되거나 가정된 경우에만 계산합니다.

MAE와 RMSE: 예측이 얼마나 틀렸을까?

오차는 예측값 − 실측값입니다. 부호가 서로 상쇄되지 않도록 MAE는 절댓값을, RMSE는 제곱을 사용합니다.

MAE = |오차|의 평균

RMSE = √(오차²의 평균)

RMSE는 큰 오차에 더 큰 비중을 줍니다. 예를 들어 가상의 오차가 1, 1, 4이면 MAE는 2, RMSE는 약 2.45입니다. 예측 오차가 작더라도 규격 경계 근처에서는 판정이 달라질 수 있습니다.

04 / CLASSIFICATION

불합격을 얼마나 잘 찾아낼까?

SECOM에서는 각 생산 샘플에 대해 합격(-1) 또는 불합격(1)이 정답입니다. 여기서는 불합격을 양성(positive)으로 둡니다. 불량 여부를 예측하는 분류 모델은 센서값과 검사 결과의 관계를 학습하지만, 특정 설비 고장의 종류나 원인을 자동으로 증명하지는 않습니다.

정답과 예측을 교차해 보기

가상 수치: 1,000개 중 실제 불합격 50개

TP · 40
실제 불합격 → 불합격 예측
FN · 10
실제 불합격 → 합격 예측
FP · 30
실제 합격 → 불합격 예측
TN · 920
실제 합격 → 합격 예측
재현율 = TP / (TP + FN)

실제 불합격 중 잡아낸 비율: 40 / 50 = 80%. 놓치는 불합격이 줄어드는지 봅니다.

정밀도 = TP / (TP + FP)

불합격이라고 알린 것 중 실제 불합격 비율: 40 / 70 ≈ 57.1%. 불필요한 경보 부담을 봅니다.

정확도는 96%지만, 전부 합격으로 예측해도 95%입니다. 불합격이 적으면 정확도만으로는 놓친 불합격을 알기 어렵습니다. F1은 정밀도와 재현율의 조화평균이며, PR 곡선은 여러 판정 기준에서 두 값의 관계를 보여줍니다. 하나의 숫자보다 놓친 불합격과 불필요한 경보의 비용을 함께 살펴야 합니다.

판정 기준을 바꾸면?

불합격 점수가 기준 이상이면 불합격으로 표시합니다.


기준 0.5: TP 40, FN 10, FP 30, TN 920 → 재현율 80%, 정밀도 57.1%

05 / VALIDATION

처음 보는 데이터로 검증하기

  1. 분할부터: 학습·검증·최종 평가 데이터를 나눕니다. 시점, Lot, 설비 같은 정보가 있다면 실제 적용 상황에 맞는 시간 또는 그룹 분할을 고려합니다.
  2. 학습 데이터로만 준비: 결측값 대체, 스케일링, 변수 선택과 모델 튜닝을 학습 데이터에 맞추고 검증·평가 데이터에는 그 결과만 적용합니다. 교차검증에서도 각 학습 폴드 안에서 수행합니다.
  3. 미래 정보를 넣지 않기: 예측 시점 이후에 얻은 측정값이나 결과 관련 정보를 입력에 넣으면 데이터 누출이 생겨 성능이 과대평가될 수 있습니다.
  4. 운영 전 검증: 시간에 따른 공정 변화, 경보의 비용, 예측 불확실성과 새로운 고장 유형을 확인하고 실측·엔지니어 검토와 함께 사용합니다.
공개 데이터에서 시간·Lot·장비 식별 정보가 없으면 해당 방식의 검증을 수행할 수 없습니다. 그때는 무작위 분할 결과의 적용 범위를 명시합니다. SECOM의 pass/fail 분류만으로 모든 종류의 공정 이상을 탐지했다고 볼 수 없습니다.
06 / KEY TERMS

프로젝트 3 용어 정리

공정과 데이터

계측 · 실측
측정 장비로 실제 물리량을 읽는 일과 그 결과입니다. 이 프로젝트에서는 웨이퍼의 박막 두께를 측정합니다.
가상계측 (Virtual Metrology, VM)
과거 센서값과 실측 결과를 배운 모델로 새로운 웨이퍼의 품질을 추정하는 방법입니다. 모델의 출력은 측정값이 아니라 예측값입니다.
센서 · 특성 (Feature)
센서는 공정 상태를 측정하는 장치이고, 특성은 모델에 넣는 입력값입니다. 예를 들어 공정 중 센서값을 요약한 평균을 특성으로 쓸 수 있습니다.
타깃 · 라벨 (Target · Label)
모델이 맞히도록 학습하는 정답입니다. PVD에서는 측정한 두께가 회귀 타깃이고, SECOM에서는 합격 또는 불합격이 분류 라벨입니다.

모델을 만들고 평가하기

회귀 (Regression)
두께처럼 연속적인 숫자를 예측하는 방법입니다. 다중회귀는 여러 입력값을 함께 사용해 결과를 추정합니다.
분류 (Classification)
입력을 보고 미리 정한 범주를 예측하는 방법입니다. SECOM에서는 합격과 불합격 중 하나를 예측합니다.
모델 학습
과거 입력과 정답의 관계를 바탕으로 예측에 쓰일 규칙을 맞추는 과정입니다.
학습 · 검증 · 시험 데이터
학습 데이터는 모델을 맞추고, 검증 데이터는 모델과 설정을 고르는 데 사용합니다. 시험 데이터는 선택을 마친 모델의 성능을 마지막에 평가합니다.
하이퍼파라미터 · 튜닝
학습 전에 정하는 모델의 설정과 그 설정을 검증하며 고르는 과정입니다. 예를 들어 트리가 얼마나 깊게 나뉠지를 조절합니다.
데이터 누출 (Data Leakage)
예측 시점에 알 수 없는 정보나 평가 데이터의 정보가 학습에 섞여, 실제보다 성능이 좋게 보이는 문제입니다.
MAE · RMSE
예측값과 실측값 사이의 오차를 요약하는 지표입니다. MAE는 오차 절댓값의 평균이고, RMSE는 오차를 제곱해 평균 낸 뒤 제곱근을 취해 큰 오차에 더 민감합니다.

불합격 분류 이해하기

혼동행렬 (Confusion Matrix)
실제 결과와 모델의 예측을 교차해 맞힌 수와 틀린 수를 정리한 표입니다. 이 페이지에서는 불합격을 양성으로 둡니다.
TP · FN · FP · TN
실제 불합격을 불합격으로 맞히면 TP, 합격으로 놓치면 FN입니다. 실제 합격을 불합격으로 잘못 알리면 FP, 합격으로 맞히면 TN입니다.
재현율 · 정밀도
재현율은 실제 불합격 중 찾아낸 비율입니다. 정밀도는 불합격으로 예측한 것 중 실제 불합격인 비율입니다.
임계값 (Threshold)
모델의 점수를 불합격 판정으로 바꾸는 기준입니다. 기준을 바꾸면 놓치는 불합격과 잘못 울리는 경보가 달라질 수 있습니다.
클래스 불균형
합격과 불합격처럼 각 범주의 개수가 크게 다른 상태입니다. 불합격이 적으면 정확도만 보고 모델을 평가하기 어렵습니다.
이상탐지
정상적인 상태와 다르거나 문제가 있을 가능성이 있는 사례를 찾는 일입니다. SECOM의 합격·불합격 분류는 모든 고장 유형을 식별하는 것과 같지는 않습니다.
